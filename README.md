# Water and sanitation affordability in Brazil, 1995 to 2022

[![DOI](https://zenodo.org/badge/1336139109.svg)](https://doi.org/10.5281/zenodo.21968532)

Reproduction code and manuscript source for a study testing whether utility
planning variables (investment level and stability, financing structure,
billing losses) explain water and sanitation affordability across Brazilian
municipalities over nearly three decades, and projecting coverage and
affordability toward Brazil's 2033 legal universalization deadline.

Submitted to a Springer Nature *Water Resources Management* special issue,
"Water Utility Planning for Customer Equity Outcomes".

## What this repository contains

- **`scripts/`** — the full numbered analysis pipeline, from raw panel
  construction through the panel regression models, robustness checks,
  machine learning forecasts (gradient boosting, random forest) and every
  figure in the manuscript. See `scripts/README.md` for execution order,
  inputs/outputs, environment versions and random seeds.
- **`sn-article-template/`** — the manuscript source (`sn-article.tex`) and
  compiled PDF (`sn-article.pdf`), using the Springer Nature LaTeX template.
- **`figuras/`** — all manuscript figures (PNG), as generated by the
  scripts.
- **`dados_brutos_externos/`** — small cached responses from public APIs
  (IBGE SIDRA, IBGE malha, PNADC) used by the pipeline, kept here so results
  reproduce exactly without re-querying those APIs.
- **`plano_artigo.md`** — a running project log documenting methodology
  decisions, data sources and the reasoning behind each analysis choice, in
  Portuguese.

## Data

The municipal panel is built from the National Sanitation Information
System (SNIS), IBGE (minimum wage, GDP, population, population
projections), Open-Meteo (precipitation) and PNADC (state level income
robustness check), all public sources with no authentication required. See
`scripts/README.md` for exact API endpoints and table identifiers.

Large raw and intermediate data files (the constructed panel and its
derivatives, tens of megabytes) are not tracked in this repository to keep
it lightweight. They are fully reconstructible by running the scripts in
order against the public sources above, and are deposited separately, see
the manuscript's Data availability statement.

## Reproducing the analysis

```
cd scripts
python 01_build_painel_icr_sm.py
python 02_descritiva_icr.py
...
```

Scripts must be run in numeric order, each depends on outputs written by
earlier ones to the project root. See `scripts/README.md` for the full
table of what each script reads and writes, and for the exact package
versions used.
