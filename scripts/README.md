# Reproduction pipeline

Scripts for "Testing Whether Utility Planning Moves Water and Sanitation
Affordability, A Three Decade Municipal Panel and Coverage Forecast for
Brazil". Run in numeric order from the project root (one level above this
folder), each script reads its inputs from and writes its outputs to the
project root, `dados_brutos_externos/` (cached external API responses) or
`figuras/` (all PNG outputs referenced in the article).

Note: scripts 01 to 15 were written before this `scripts/` and `figuras/`
convention was formalized, some early intermediate files they depend on
were produced by earlier, unnumbered exploratory work and are provided
directly as CSVs in the project root rather than regenerated by a script
here. Scripts 16 onward are self contained and regenerate everything they
need from `br_painel_analise_final.csv` and public API sources.

never discarding analysis code, but the figure is not referenced in the
final manuscript.

## Random seeds

All `HistGradientBoostingRegressor`, `RandomForestRegressor` and
`permutation_importance` calls use `random_state=42`. No other stochastic
steps are involved, the panel regressions (`PanelOLS`) and linear
extrapolations are deterministic given the input data.

## External API sources (not requiring authentication)

- SNIS municipal panel: https://www.gov.br/cidades/pt-br/assuntos/saneamento/snis
- IBGE minimum wage history: https://ftp.ibge.gov.br/Salario_Minimo/evolucao_do_salario_minimo.xls
- IBGE SIDRA (GDP, population, population projection): https://sidra.ibge.gov.br/
- Open-Meteo historical weather archive: https://open-meteo.com/
- PNADC household survey (state income denominator robustness check)
- IPEAdata (IDHM-renda, not used in the final manuscript): http://www.ipeadata.gov.br/
- IBGE malha geographic boundaries API: https://servicodados.ibge.gov.br/api/v3/malhas/
